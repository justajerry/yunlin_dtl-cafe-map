# 雲林斗六、莿桐、林內咖啡地圖 

專為探索雲林斗六、莿桐、林內特色獨立咖啡館設計的互動式地圖，支援行政區快篩、關鍵字即時搜尋、深夜咖啡館篩選以及 GPS 距離排序功能。

## 📚 資料來源與版權宣告

本專案非商業使用，僅供個人與社群咖啡愛好者探索交流：

1. **咖啡館資料來源**：
   - 店家清單、地址、營業時間整理自 **Google Maps** 與 **Cafe Nomad (cafemad)** 公開社群資料庫。
2. **地圖圖磚與技術組件**：
   - **底圖圖磚 (Map Tiles)**：[Esri World Street Map](https://www.arcgis.com/home/item.html?id=3b93337983e9436f8db950e38a8629af) (Tiles &copy; Esri)
   - **地圖核心套件**：[Leaflet.js](https://leafletjs.com/) (BSD 2-Clause License)
   - **點位聚集套件**：[Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster) (MIT License)

## ⚠️ 免責聲明

地圖所載之營業時間、公休日與店家聯絡方式僅供參考。店家實際營業狀況請以現場及官方社群專頁最新公告為準。如需更新、回報店家異動或撤下資訊，歡迎聯絡作者。
